Design principles

Carried forward from the parts twin, the sibling repo this schema extends.

SAP-shape schema Column names mirror MARA / MARC / MARD / MBEW / MATDOC / MVKE. When PACCAR sends an SAP payload, it maps 1:1. When the dealer group leaves a vendor, the field names still make sense.
One adapter per external system, not per site CDK Drive (Fortellis), PACCAR's dealer-facing systems, and a file-export fallback path — three adapters cover all nine Peterbilt Atlantic sites.
Never invent a field or endpoint Every name in this repository traces to a public source. Where no public source exists, the file says so explicitly rather than filling the gap with a plausible guess.
