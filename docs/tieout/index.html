Why June, and what "tied out" means here

Three months are captured (May–July 2026 by default); the middle month is the tie-out target because it is the only one bracketed on both sides — a full prior month to catch schedule items that opened before the window, a full following month to catch items that clear after it.

What's behind this board

The method and the code that runs it, once the extract exists.

tieout/README.md

Five reconciliation statements, in order of increasing difficulty — from transaction completeness through the absorption-rate recompute — each with its formula, its input files, expected variance sources, and pass criterion.

tieout/bin/reconcile.py

The reconciliation script itself — stdlib Python, pandas-optional, reads the normalised extract output, emits a markdown + JSON report with per-statement pass/fail and a populated break register. Runs cleanly with --help even before any extract exists.
